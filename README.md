# javascript-lotto-precourse

# 로또 프로젝트

## 개요

사용자로부터 구매 금액을 입력받아 로또를 자동으로 발행하고,
당첨 번호와 보너스 번호를 입력받고 자동 발행한 로또와 비교하여 등수와 수익률을 계산

## 기능 목록

### 1. 로또 구매

- 사용자가 구입 금액을 입력한다.
   - 1,000원 단위로 입력
   - 로또 1장 = 1,000원
- 발행된 로또 수량을 출력한다.
- 발행된 모든 로또의 번호들을 출력한다.
   - 번호는 오름차순으로 정렬
   - 로또 번호는 1 ~ 45 사이의 숫자로 구성된다.
   - 하나의 로또는 중복되지 않는 6개의 숫자를 가진다.

### 2. 당첨 확인

- 당첨 번호 6개를 입력받는다.
   - 쉼표(,)로 구분
   - ex: 1,2,3,4,5,6
- 보너스 번호를 1개 입력 받는다.
- 발행된 모든 로또들이 몇등인지 확인한다.

### 3. 로또들의 당첨 등수와 수익률 출력

- 등수별 당첨 개수를 출력한다.
- 총 수익률을 계산하여 출력한다.
   - 수익률은 소수점 둘째자리에서 반올림한다.

## 예외 처리

### 구입 금액
- 숫자가 아닌 값이 입력되면 에러 발생
- 1,000원 단위가 아니면 에러 발생

### 당첨 번호
- 6개가 아니면 에러 발생
- 중복된 숫자가 있으면 에러 발생
- 숫자와 쉼표 이외의 문자가 포함되어 있으면 에러 발생
- 1 ~ 45 사이의 숫자가 아니면 에러 발생

### 보너스 번호
- 숫자가 아니면 에러 발생
- 1 ~ 45 사이의 숫자가 아니면 에러 발생
- 당첨 번호와 중복되면 에러 발생
