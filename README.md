# javascript-lotto-precourse

# 로또 프로젝트

## 기능 목록

### 입력

사용자가

1. 로또 구입 금액
2. 당첨 번호(쉼표로 구분)
3. 보너스 번호
   를 입력한다.

### 입력 예외 상황

1. 로또 구입 금액에 숫자 이외의 글자가 적혀있다.
2. 로또 구입 금액이 1,000원 단위가 아니다.
3. 당첨 번호에 숫자와 쉼표 이외의 글자가 적혀있다.
4. 당첨 번호에 로또 숫자범위 밖의 숫자가 적혀있다.
5. 보너스 번호가 로또 숫자범위 밖이다.
6. 보너스 번호가 숫자 이외의 글자가 포함되어 입력되었다.

### 출력

1. 발행한 로또 수량
2. 발행한 로또들의 번호(오름차순 정렬)
3. 당첨 내역 출력
4. 수익률 출력(소수점 둘째자리에서 반올림)
